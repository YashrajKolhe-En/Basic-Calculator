# 🧮 Basic Calculator

A simple and responsive **Basic Calculator Web Application** built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations through an easy-to-use graphical interface and also supports keyboard input.

## 📌 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* `%` Percentage/Modulo operation
* 🔢 Decimal number support
* 🧹 Clear (`AC`) button
* ⌫ Delete (`DEL`) button
* ⚡ Real-time display
* ⌨️ Keyboard support
* 🚫 Division-by-zero handling
* 📱 Responsive and modern UI
* ✨ Button hover and click animations

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Calculator logic and user interaction

## ⌨️ Keyboard Shortcuts

| Key           | Function          |
| ------------- | ----------------- |
| `0 - 9`       | Enter numbers     |
| `+`           | Addition          |
| `-`           | Subtraction       |
| `*`           | Multiplication    |
| `/`           | Division          |
| `%`           | Modulo            |
| `Enter` / `=` | Calculate result  |
| `Backspace`   | Delete last digit |
| `Esc`         | Clear calculator  |


## 🧮 Example

Input:
25 + 15
